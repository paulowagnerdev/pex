## 📋 Sobre o Projeto - PEX Católica

O objetivo deste projeto é criar uma landing page para uma barbearia, oferecendo uma experiência visual agradável e intuitiva para os visitantes.

O site conta com:

- Banner principal com imagem de destaque
- Menu de navegação com rolagem suave entre seções
- Seção "Sobre a Barbearia"
- Apresentação dos serviços
- Design responsivo para dispositivos móveis
- Efeitos visuais modernos utilizando CSS
